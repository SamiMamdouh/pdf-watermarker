# Ism — PDF Watermark Studio

The browser app is available at [samimamdouh.github.io/pdf-watermarker](https://samimamdouh.github.io/pdf-watermarker/). It runs entirely in your browser: PDFs and names are not uploaded.

GitHub Pages is a public static host, so this version has no login or access control. Use the separately hosted Node.js server for the username-and-password protected version; do not put credentials in this repository.

Choose a PDF, enter one name per line, and select **Preview all copies** to create and review a personalized PDF before downloading or printing. To run locally, use Node.js 22 or newer and follow `README.txt`.
